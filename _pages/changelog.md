# Changelog

## Version 2.3
Android app launch. Same features as iOS version. 


#### What's New
- Tap countdown timer to toggle it to absolute time
- Share button added so you can let friends or family know of prayer time
- UI improvements
- More animations on Insights/Stats page
- Added a toast to show when notifications/alarms are fully set
- Select prayers page background during onboarding now
- Add date at top of Insights/Stats page.

#### Bug Fixes
- Brunei was showing as 26 degrees Fajr angle in error. It is and always has been 20 degrees
- Fixed possible import errors for Flo and Clue imports
